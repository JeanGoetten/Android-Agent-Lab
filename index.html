01 / CURRENT FOCUS

Project control on Android

The primary engineering problem is reliable control of user development projects under mobile-platform constraints. AI models are one layer of that system, not the whole product.

02 / MODEL EXECUTION
LOW-END ANDROID API-based models are currently the primary path.

Local inference remains a secondary capability. On low-end hardware, CPU-only throughput can make interactive execution impractical. Local-model results are therefore kept as a separate evaluation track rather than treated as the project's general performance target.

The test program can exercise multiple API models in the same development workflow. Model choice is evaluated in the context of project control, reliability, latency, cost, and recovery rather than by throughput alone.
